# 扫描自查工具 - 界面

## 目录结构
```shell
<项目根目录>
|____app/           (源码目录)                              
    |____3thrd/     (第三方的开源库)
    |____data/      (源码依赖的二进制数据文件)
    |____main.cpp   (界面主程序入口)
    |____model/     (model层，用来包含表格数据)
    |____res.qrc    (qt资源文件，整合app/data/目录下的二进制资源，编译到最终生成的二进制文件中)
    |____ui         (整个ui界面布局以及用到的一些自定义小组件)
    |____view       (view层，主要是两个表格)
|____demo/          (一些模块调试过程中用的二进制)
|____sql/           (显示数据的sqlite3表结构)
```
